# 机械类面试刷题

这是一个可部署到 GitHub Pages 的机械类复试刷题工具，包含专业知识问答、押题模块、英文翻译、错题本、模拟面试和本地数据备份。

## iPhone 使用

部署到 GitHub Pages 后，用 iPhone Safari 打开网址，点击分享按钮，选择“添加到主屏幕”，之后即可像 App 一样打开。

学习记录保存在 iPhone Safari 本地。换手机或清理浏览器前，请先在软件里的“数据备份”中导出备份文件。

## 需要上传的文件

请上传 `mobile-deploy` 文件夹中的所有文件到本仓库根目录。

- `index.html`
- `styles.css`
- `app.js`
- `questions.js`
- `prediction_questions.js`
- `translation_questions.js`
- `sentence_translation_questions.js`
- `sentence_translation_extra_questions.js`
- `manifest.webmanifest`
- `sw.js`
- `app-icon.svg`
